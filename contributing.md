# Getting Started

Fork the repository.

Clone your fork:

```bash
git clone https://github.com/your-username/teloce.git
cd teloce
```

Create a new branch:

```bash
git checkout -b feature/my-feature
```

Install dependencies:

```bash
pnpm install
```

or

```bash
npm install
```

Start the development server:

```bash
pnpm dev
```

---

# Development Workflow

1. Create a feature branch.
2. Make your changes.
3. Test everything thoroughly.
4. Update documentation if necessary.
5. Commit your work.
6. Push your branch.
7. Open a Pull Request.

# Coding Standards

Please follow these guidelines.

## JavaScript

* Use modern ES6+ syntax.
* Prefer `const` and `let`.
* Avoid global variables.
* Write readable code.
* Keep functions focused.

---

## Vue Components

* Keep components reusable.
* Avoid duplicated logic.
* Use descriptive names.
* Keep templates clean.

---

## HTML

* Use semantic HTML elements.
* Maintain accessibility.
* Keep indentation consistent.

---

## CSS

* Prefer Tailwind utility classes.
* Minimize custom CSS.
* Remove unused styles.

---

# Commit Guidelines

Write clear, concise commit messages.

Examples:

```text
feat: add playground sidebar

fix: resolve router navigation bug

docs: improve installation guide

style: clean up code formatting

refactor: simplify search component
```

# Pull Requests

Before submitting a Pull Request, ensure that:

* Your code builds successfully.
* No existing functionality is broken.
* Documentation has been updated (if needed).
* Commit history is clean.
* Your branch is up to date.

Your Pull Request should include:

* A clear description
* Screenshots (if UI changes)
* Related issue numbers
* Testing information
